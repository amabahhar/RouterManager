# Ultimate Router Manager — App Backend

Runtime data files fetched by the app at launch (served via raw.githubusercontent.com):

- `version.json` — version gate + update info (keep `supported_versions` in sync with shipped builds)
- `game_servers.json`, `games_ports.json` — ping/port tools data
- `tutorials.json` — in-app tutorial links  ⚠️ still contains the previous owner's TikTok videos; replace with your own
- `Privacy_Policy`, `Terms of Use` — shown in-app  ⚠️ `support@urm.app` is a placeholder email; replace with yours
